# Proposal: Universal Voting Platform (通用多活动多模板投票平台)

## Why
目前团队已有针对特定合规视频评选的初步原型构想，但随着多场景组织评选需求（如企业标兵评选、摄影比赛、短视频竞赛）的增长，硬编码的单次活动开发成本高且无法复用。因此需要构建一个现代化的通用投票 Web 平台，支持多租户自主入驻、文字/图片/视频三种模板自由创建、灵活一人多票（不可重复投同一项）规则、动态身份扩展字段收集，并在完全公开开放的环境下提供高可靠的无感防刷与实时数据监控能力。

## What Changes
- **多租户 SaaS 账户体系**：支持租户管理员前端自主注册、登录鉴权（JWT），实现活动与媒体资源租户级隔离。
- **三类活动模板引擎**：支持“纯文字”、“图文”、“短视频”三种模版形式创建活动，统一表单式录入候选项目及媒体。
- **灵活投票规则与动态字段**：支持配置“一人固定 N 票且单作品限投 1 票”规则，支持匿名与动态实名/机构扩展字段收集。
- **本地媒体托管与流式分发**：提供最大 100MB 视频与图片本地安全存储，后端支持 HTTP 206 断点续传与毫秒级首帧拖拽。
- **动静结合的投票交互与防刷风控网**：
  - 前端自适应交互：视频模板弹窗即时单投，文字/图片模板多选批量提交；
  - 防刷体系：客户端 FingerprintJS 无感指纹 + HttpOnly 签名 Token + IP 速率桶与每日上限 + 数据库原子级防重；
- **实时数据监控与报表导出**：管理后台支持 SSE 实时动态票数跳动看板，支持一键导出含投票流水与交叉透视的多 Sheet Excel。

## Capabilities

### New Capabilities
- `tenant-auth`: 租户管理员自主注册、登录、Token 鉴权与租户数据隔离机制。
- `campaign-management`: 包含文字/图片/视频三大模板的选择、规则设置、动态表单配置、候选人表单化录入与短链生成的全流程管理。
- `media-storage`: 本地租户目录隔离文件存储，限制上传最大 100MB MP4/图片并支持 HTTP 206 Partial Content 流式播放。
- `voting-engine`: 面向大众的移动端自适应投票前端，基于设备指纹与服务端会话的状态探测、人机风控及原子入库事务。
- `realtime-analytics`: 管理端实时看板（基于 SSE 的票数翻牌推送）、作弊票一键作废治理以及多维度 Excel 报表导出。

## Impact
- **后端系统**：在 `backend/` 下采用 Python 3.13 + FastAPI + SQLAlchemy + SQLite (WAL 模式) 搭建独立微架构 API 服务。
- **前端系统**：在 `frontend/` 下采用 React 19 + Vite + TailwindCSS 打造响应式轻量 SaaS 控制台与移动端优先投票页。
- **资源目录**：在本地 `uploads/tenants/{tenant_id}/` 建立持久化媒体文件存储结构。
